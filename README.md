## DRIVA - CAR RENTAL SYSTEM

## Description: 
Built a full-stack car rental platform using MongoDB, Express.js, React.js, and 
Node.js. Users can browse cars, book rentals, and manage reservations, while admins handle 
vehicles, availability and bookings via a dashboard and deployed on Vercel. 

## Technology: 
MERN stack
